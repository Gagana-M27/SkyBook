# SkyBook – CP-046

## Dynamic-Fare Flight Reservation and Waitlist Engine

SkyBook is a Python-based console application developed for the CP-046 project. It manages flight reservations using dynamic fare calculation and passenger waitlist management.

## Features

- View all available flights
- Search flights by source and destination
- Dynamic flight fare calculation
- Book flight tickets
- View passenger reservations
- Cancel bookings
- Add passengers to a waitlist when flights are full
- Automatically promote the next waiting passenger when a seat becomes available
- Store flight and passenger data using CSV files

## Technologies Used

- Python
- CSV file handling
- Visual Studio Code

## How to Run

1. Install Python.
2. Open the SkyBook project folder in Command Prompt or VS Code.
3. Run the following command:

   `py main.py`

4. Follow the menu displayed in the terminal.

## Data Storage

The application automatically creates and updates CSV files to store flight details, reservations, and waitlist information.
